# R53–R54: Links between items, and polish

Spec: UX Redesign Specification v1, section 6 (links), 2.3/2.6 (filters, statuses), 3.5 (On this day); backlog B-17.
Decisions: D10 (links), D29–D31 in `docs/DECISION_LOG.md`.

## R53 — Links between items

| # | What changed | Where |
|---|---|---|
| 1 | **Create from this** (link-plus icon on Activity, Trip, Occasion and Experience pages; "Create from this" in a calendar event's menu): Create reminder · Add to calendar · Make a to-do · Add a note, plus type-specific actions: Trip → **Leave-for-airport reminder** (trip day 6:00 AM) and **Online check-in reminder** (day before, 9:00 AM); Activity → **Turn into trip**; Occasion → **Preparation reminder** (a week before, 9:00 AM); Experience → **Plan a date**. The new item is pre-filled (title, date, shared like its source) and **linked automatically**. | `lib/core/linked_items.dart` |
| 2 | **Linked items strip** under the title of Activities, Trips, Occasions and Experiences, inside each reminder, and as "Linked items" in a calendar event's menu. Tap a chip to open the item; **long-press to Unlink** (the item itself stays). A reminder's built-in source (to-do, event, occasion) shows here too, both ways. | |
| 3 | **Privacy:** a link to something the viewer cannot see (the partner's Only-me item) is never shown, not even as "hidden item". Tested on the live database. | table `item_links` with row-level security, `item_linked()` |
| 4 | **Trip end → last time we met:** when you live apart, marking a shared trip **Completed** updates "Last time we met" to the trip's end date (never moves it backwards). | trigger `r53_trip_end_last_met` |
| 5 | Reminder and calendar change logs now open the shared change log page (R50) instead of the old pop-up. | |

## R54 — Polish

| # | What changed |
|---|---|
| 1 | **Activities have a change log** like every other list (clock icon on Coordinate): Created, Edited, Completed (completed/bought/booked), Cancelled, Removed, Restored. |
| 2 | **On this day** on Today: at most one past memory from today's date at the top of "Today and the next 7 days" ("On this day · 2 years ago"); tap opens it; ✕ hides that memory from Today on this phone. |
| 3 | **"Showing: Removed ✕"** line under the title on Reminders, Notes, Memories, Occasions, Trips, People, Shared experiences and Items to sort while the Removed filter is on; ✕ clears it. |
| 4 | **Search** now finds **People (contacts)** and **Items to sort**; its filter uses the slider icon with a dot. |
| 5 | **Status look** (spec 2.6) in the To-do, Activities, Occasions and Trips lists: completed/bought/booked/celebrated rows are struck through and muted with a green check; cancelled rows with a red cross. |

## Test script (two phones)
1. Open a shared **Trip** → tap the link-plus icon → **Leave-for-airport reminder**: the reminder page opens with "Leave for the airport · <trip>" at 6:00 AM on the trip day, shared with both. Save. Back on the trip, the **Linked** strip shows the reminder. Open the reminder: its strip shows the trip (B-17).
2. On the trip, **Create from this → Add a note** (it opens linked); **Make a to-do** (added and linked).
3. Long-press a chip in the strip → **Unlink** → the chip disappears; the item still exists.
4. On A, create an **Only-me** note from a shared trip. On K, open the trip: the note link does **not** appear.
5. In Calendar, open an event's menu → **Create from this → Create reminder**; then **Linked items** shows it.
6. With How we live = Apart, mark a shared trip **Completed**: Today's "Last time we met" becomes the trip's end date.
7. In Coordinate, tap the clock: Activity history with chips. Mark an Activity **Bought**: a "Completed" row appears.
8. In Notes, turn on the **Removed** filter: "Showing: Removed ✕" appears under the title; ✕ turns it off.
9. In Search, type a contact's name: it appears under Contact.
10. In To-do, complete a list: it shows struck through with a green check; cancel one: red cross.
11. If you have a memory dated on today's day and month in a past year, Today shows it as **On this day**; ✕ hides it.

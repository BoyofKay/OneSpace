# R62 QA — Arabic everywhere

Me → Language → العربية. The screen should switch immediately without going back to Today.

1. Walk every tab and open one item of each kind (reminder, note, event, to-do list, activity, trip, occasion, memory, letter, daily connection, experience, contact). Titles, buttons, field labels, hints, filters, ⋮ menus, empty states and pop-ups are Arabic and laid out right-to-left.
2. Things you typed (titles, notes, names) stay exactly as written.
3. Statuses and choices are Arabic: list repeat (كل يوم…), trip status (محجوزة، قيد التخطيط…), weather (غائم جزئيًا…), gesture messages you receive.
4. Dates and times: Arabic month and day names; ص / م for AM/PM.
5. Turn on airplane mode and pull to refresh — error messages are Arabic.
6. Partner on English: anything you send (gestures, items) shows in English on their phone.
7. Push notifications arrive in each person's language.
8. Report any English you still see with a screenshot — each is a one-line addition to lib/l10n/phrases_ar.dart.

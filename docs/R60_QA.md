# R60 — Voice, read aloud and the app icon: test script

| # | Do | Expect |
|---|---|---|
| 1 | Install over 0.1.426 | Home-screen icon is the OneSpace mark (on Android 13+ with themed icons on, it follows your wallpaper colours). Logo next to "OneSpace" in the top bar. |
| 2 | Shared experiences › rate an item | Five stars on one line; tap a star again to clear. |
| 3 | Shared experiences pop-up | Plan · Another · View as three equal blocks inside the card. |
| 4 | Tap the mic (top bar) › "Remind me to call the clinic tomorrow at 5 pm" | Reminder page opens with the title and tomorrow 5:00 PM filled in. Nothing saved until Save. |
| 5 | "Add milk and eggs to the groceries list" | Snackbar "Added Milk, Eggs to Groceries" with Undo. (No such list → opens New list.) |
| 6 | "Take a note: the Wi-Fi password is on the router" | New note page pre-filled. |
| 7 | "Add an event dinner with Sara on Saturday at 7:30 pm" | Event page: title, Saturday, timed 7:30–8:30 PM. |
| 8 | "What's on today?" / "Read my reminders" / "Read my latest note" | Phone reads them aloud; "Stop" in the bar stops it. |
| 9 | "Open the calendar", "Search for passport", "Send a little love", "What can I say?" | Opens the screen / search with results / A little love / the examples sheet. |
| 10 | Say something else ("buy flowers for Kay") | Sheet: Reminder · Note · Event · To-do list with your words. |
| 11 | Any ⋮ menu › Read aloud; a letter › speaker icon | Reads the item. |

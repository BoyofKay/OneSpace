# R67 QA — Trips, Occasions & gifts, note formatting (forms review part 2)

## Trips
1. Coordinate › Trips › Add trip: How (Flight/Road trip/Train/Other), Trip type (Round trip/One way — one way hides Coming back), From/To open an airport search (type "Riyadh", "phila" or "RUH"); road/train trips have plain text. Who's traveling chips + Adults/Children/Infants steppers. Button says **Next** → the trip page opens.
2. Status chip shows Planning. ⋮ › Search on Google Flights opens Google Flights already filled (airports, dates, passengers, one way).
3. In Google Flights tap Share › OneSpace → "Flight option for a trip" is suggested → choose the trip → the option opens with airports/dates (and airline/price if in the text). Or copy the link and tap **Paste a flight** in Flights.
4. Flight option: one Link (✨ fills from it), stops chips, Cabin bags / Checked bags, Seat chosen + number, Status. Save as **Booked** → asked to add to the itinerary; trip status becomes **Booked**; Flights section collapses with a green tick.
5. Itinerary item: ⋮ (Edit · Open booking link · Remove); no Done button. A new flight starts with the trip airports and title "RUH → PHL".
6. Documents card sits right under the trip summary, tinted, with Attach.
7. ⋮ › Add a travel checklist (sheet of 4); made lists show under "Travel checklists". No Change history at the bottom.
8. ⋮ › Cancel trip → Cancelled; ⋮ › Reopen → automatic status again. After the return date the trip shows Past and leaves Upcoming.

## Occasions & gifts
9. Add occasion: tap "Pick a special date or holiday" → yearly calendar events and the regional holidays you follow → title/date/kind fill in. For whom chips; Start preparing 1 week/2 weeks/1 month; Budget + Currency; Next → occasion page. Reminders shows "Start preparing: …" on that day.
10. Occasion page: first ideas at the top, date card (days left, date, Start preparing … · reminder set). No Related notes, Preparation, Change history.
11. Planning intelligence → + Add a gift option: Status Wishlist/Considering; Cost row Quantity | Price | Currency; Shop, link, stars, shop rating.
12. Gifts groups are collapsed (Ideas, Reserved, Purchased, Excluded). ⋮ on a gift: Reserve → budget Reserved goes up; Mark as purchased → Paid (prefilled), order status/number/tracking/delivery → Spent goes up. When every reserved gift is bought, the occasion shows Ready.
13. Compare icon (↔) next to Gifts → pick gifts → save a list → "Use this list" reserves them.
14. After the date the occasion shows Past and leaves Upcoming.

## Notes
15. New note: the formatting bar shows Title/Heading/Text and big buttons with words (Bold, Italic, Underline, Highlight, Colour, Bullets, Numbers, Checklist, Quote, Link, Clear, Undo, Redo). Select a word → Highlight → Yellow.

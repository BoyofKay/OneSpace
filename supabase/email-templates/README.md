# OneSpace email standard

One brand for every email a user receives from the app.

| Item | Standard |
|---|---|
| Sender (From) | `OneSpace <support@onespace.live>` for every app email: Supabase Auth SMTP in QA **and** Production, and the partner invitation |
| Reply-To | `support@onespace.live` (a real Zoho mailbox, so replies are read) |
| Logo | `https://onespace.live/assets/icon-512.png` |
| Tagline | `Two of Us. One Space.` (same as `OneSpaceBrand.tagline`) |
| Colours | Navy `#14213D` text, button and links `#234D82`, page `#F3F6FA` |
| Footer | OneSpace · tagline · onespace.live · support@onespace.live |
| Language | English only for app emails (for now) |

Website Founder emails (`OneSpace Founders <founders@onespace.live>`) and internal website-form mail (`OneSpace Website <website@onespace.live>`) live in the `onespace-app` repo and are not covered here.

## Supabase Auth templates

Generated by `python3 supabase/email-templates/build.py`. Never hand-edit the HTML; change `build.py` and rebuild.

Paste each file into **Authentication → Emails → Templates** with this exact subject. QA first; Production only after QA is accepted.

| Dashboard template | File | Subject | Used by the app today? |
|---|---|---|---|
| Confirm signup | `confirmation.html` | Confirm your OneSpace email address | Yes (sign up, resend) |
| Invite user | `invite_user.html` | You're invited to OneSpace | No (dashboard invites only) |
| Magic link | `magic_link.html` | Your OneSpace sign-in link | No |
| Change email address | `email_change.html` | Confirm your new OneSpace email address | No |
| Reset password | `password_recovery.html` | Reset your OneSpace password | Yes (forgot password, change password) |
| Reauthentication | `reauthentication.html` | Your OneSpace verification code | No |
| Security: Password changed | `password_changed_notification.html` | Your OneSpace password was changed | Only if the notification is switched on |
| Security: Email address changed | `email_changed_notification.html` | Your OneSpace email address was changed | Only if the notification is switched on |

Unused templates are branded anyway so that no Supabase-default email can ever reach a user.

## SMTP (both projects)

Authentication → Emails → SMTP Settings: host `smtp.resend.com`, sender email `support@onespace.live`, sender name `OneSpace`. The Resend domain `onespace.live` must be verified (SPF + DKIM).

**A commit is not proof a template is live.** Confirm by receiving the email.
